# 게임 프로토타입

Unity 6.3 LTS 기반의 **2D 탑다운 액션 어드벤처 게임 프로토타입**입니다.

본 프로젝트는 PIXEL LABS에서 개발 중인 게임의 주요 시스템을 구현하고 검증하기 위해 제작되었습니다.

플레이어 이동과 전투, 적 AI, 방 전환, NPC 대화 시스템을 포함하고 있으며, 현재 게임의 핵심 기능과 레벨 구조를 테스트하는 단계입니다.

그래픽과 오브젝트는 기능 검증을 위한 임시 리소스를 사용하고 있습니다.

## 시작하기

### 1. 프로젝트 다운로드

GitHub 저장소에서 `Code → Download ZIP`을 선택하여 프로젝트를 다운로드합니다.

또는 Git을 이용해 저장소를 복제할 수 있습니다.

```bash
git clone https://github.com/chocho-pixel/GamePrototype.git
```

특정 브랜치의 프로젝트를 사용하려면 해당 브랜치를 선택하여 다운로드하거나 복제해야 합니다.

### 2. Unity 프로젝트 추가

1. Unity Hub를 실행합니다.
2. `Projects` 메뉴를 선택합니다.
3. `Add → Add project from disk`를 선택합니다.
4. 다운로드한 프로젝트 폴더를 지정합니다.
5. Unity Editor 6000.3.27f1 버전으로 프로젝트를 엽니다.

프로젝트를 처음 열 때 Unity가 에셋을 임포트할 수 있습니다.

### 3. 프로토타입 실행

Unity 에디터에서 다음 씬을 엽니다.

`Assets/Scenes/Prototype.unity`

씬을 연 뒤 상단의 **Play** 버튼을 누르면 실행됩니다.

## 조작 방법

| 입력 | 기능 |
|---|---|
| E | 문 및 NPC 상호작용 |
| Space | 대사 진행 |
| Space (타이핑 중) | 대사 즉시 완성 |
| 마우스 좌클릭 | 대화 선택지 선택 |

플레이어 이동, 대시 및 공격은 프로젝트에 설정된 기존 입력 방식을 사용합니다.

## 구현된 시스템

### 1. 플레이어와 전투

플레이어는 2D 탑다운 시점에서 이동하고 적과 전투할 수 있습니다.

**플레이어 기능**
- 캐릭터 이동
- 대시
- 기본 공격
- 체력 및 피해 판정
- 사망 처리
- 게임 재시작

**전투 시스템**
- 플레이어 공격 판정
- 적과 플레이어의 충돌 처리
- 체력 감소 및 사망 판정
- 체력 UI 표시

플레이어의 체력은 화면에 하트 형태로 표시됩니다.

### 2. 적 AI

기존 프로토타입에는 플레이어를 추적하는 몬스터가 구현되어 있습니다.

**주요 기능**
- 플레이어 탐지 및 추적
- A* 경로 탐색
- 장애물 회피 경로 계산
- 벽과 장애물 충돌 처리
- 플레이어와의 전투

몬스터는 자신이 배치된 공간에서만 활동합니다.

현재 테스트용 몬스터는 **0번 홀**에 배치되어 있으며, 플레이어가 다른 방으로 이동해도 따라오지 않습니다.

### 3. 맵 및 공간 시스템

현재 맵은 여러 방과 복도로 이루어진 구조입니다.

각 방은 독립적인 게임 공간으로 관리됩니다.

**구현된 기능**
- 방별 공간 관리
- 벽 및 장애물 충돌
- 문을 이용한 공간 이동
- 방 전환 시 페이드 효과
- 공간 전환 후 플레이어 위치 지정
- 카메라 추적

플레이어가 문에 접근하면 상호작용 안내가 나타납니다.

`[E] Open door`

E키를 누르면 연결된 공간으로 이동합니다.

현재 맵은 구조 검증 단계에 있으며, 세부 레벨 디자인은 추후 수정될 예정입니다.

### 4. NPC 대화 시스템

1번 로비에 테스트용 NPC가 배치되어 있습니다.

NPC는 분홍색 삼각형으로 표현되며, 캐릭터 상단에 `NPC` 이름표가 표시됩니다.

NPC 근처에서 E키를 누르면 대화를 시작할 수 있습니다.

**대화 시스템 기능**
- NPC 접근 및 상호작용
- 화자 이름 표시
- 대사 타이핑 효과
- 스페이스바를 이용한 대사 진행
- 마우스 기반 선택지
- 대화 중 플레이어 조작 제한
- 대화 종료 후 조작 복구
- NPC와 반복 대화

#### 대화 진행 방식

대사는 한 번에 출력되지 않고 글자가 순서대로 나타나는 타이핑 효과를 사용합니다.

타이핑 도중 스페이스바를 누르면 현재 문장이 즉시 완성됩니다.

문장이 완성된 상태에서 다시 스페이스바를 누르면 다음 대사로 진행됩니다.

#### 선택지 시스템

NPC의 특정 대사가 완료되면 선택지가 자동으로 표시됩니다.

선택지는 세로 방향으로 정렬되며, 플레이어는 마우스로 원하는 항목을 선택할 수 있습니다.

현재는 선택지 입력 및 대화 진행 기능을 검증하기 위한 테스트 대사가 적용되어 있습니다.

### 5. 화면과 UI

현재 프로토타입에는 다음 UI 요소가 구현되어 있습니다.

- 플레이어 체력 표시
- 게임 오버 및 재시작 UI
- 문 상호작용 안내
- NPC 상호작용 안내
- 대화창
- NPC 화자 이름
- 대화 선택지

UI는 현재 기능 검증을 위한 임시 디자인입니다.

## 프로젝트 구성

```text
GamePrototype/
│
├── Assets/
│   ├── Editor/
│   ├── Scenes/
│   │   └── Prototype.unity
│   ├── Scripts/
│   └── Settings/
│
├── Packages/
│
├── ProjectSettings/
│
├── AGENTS.md
├── PLAN.md
├── PROJECT.md
├── STATUS.md
│
└── README.md
```

### 주요 구성 요소

| 구성 | 역할 |
|---|---|
| Assets/Scenes | 게임 씬 |
| Assets/Scripts | 게임플레이 C# 코드 |
| Assets/Editor | 에디터 및 씬 구성 도구 |
| Assets/Settings | 프로젝트 에셋 설정 |
| Packages | Unity 패키지 의존성 |
| ProjectSettings | 프로젝트 환경 및 엔진 설정 |

실제 파일 구성은 개발 진행에 따라 변경될 수 있습니다.
