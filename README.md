# GamePrototype

**PIXEL LABS | Unity 2D Game Prototype**

PIXEL LABS에서 개발 중인 2D 탑다운 게임의 시스템 및 레벨 구현을 검증하기 위한 프로토타입입니다.

Unity를 기반으로 캐릭터 조작, 전투, 몬스터 AI, 맵 이동, NPC 상호작용 등 주요 게임 시스템을 구현하고 테스트하고 있습니다.

현재 프로젝트는 개발 및 기능 검증 단계에 있으며, 실제 게임의 최종 그래픽이나 레벨 디자인과는 차이가 있을 수 있습니다.

## 개발 환경

| 항목 | 내용 |
|---|---|
| 게임 엔진 | Unity 6.3 LTS |
| 권장 Unity 버전 | 6000.3.27f1 |
| 언어 | C# |
| 장르 | 2D 탑다운 액션 어드벤처 |
| 개발팀 | PIXEL LABS |
| 개발 상태 | Prototype |

## 구현된 기능

### 1. 플레이어 시스템
- 2D 탑다운 캐릭터 이동
- 대시 및 공격
- 체력 및 피해 판정
- 사망 및 게임 재시작

### 2. 전투 및 몬스터 AI
- 몬스터의 플레이어 추적
- A* 기반 경로 탐색
- 장애물 및 벽 충돌
- 몬스터와 플레이어의 전투

### 3. 맵 및 공간 시스템
- 독립적인 방 구조
- E키를 이용한 문 상호작용
- 방 전환 및 페이드 효과
- 이동 가능 영역 및 충돌 판정
- 카메라 추적

현재 맵은 레벨 구조 검증을 위한 임시 구현이며, 추후 설계도에 맞춰 수정할 예정입니다.

### 4. NPC 대화 시스템
- NPC 접근 후 E키로 대화 시작
- 한 글자씩 출력되는 타이핑 효과
- 스페이스바를 이용한 대사 진행
- 마우스 클릭 방식의 선택지
- 대화 중 플레이어 조작 제한
- 대화 종료 후 조작 복구

NPC 대화 시스템은 현재 테스트용 대사를 사용하고 있습니다.

## 조작 방법

| 입력 | 기능 |
|---|---|
| 이동 키 | 캐릭터 이동 (실제 키 배치는 프로젝트 설정 참조) |
| E | 문 및 NPC 상호작용 |
| Space | 대사 진행 / 타이핑 즉시 완료 |
| 마우스 좌클릭 | 대화 선택지 선택 |

전투 및 대시 조작은 현재 프로젝트의 입력 설정을 참고해 주세요.

## 프로젝트 실행 방법

### 1. 프로젝트 다운로드

GitHub 저장소에서 다음 순서로 다운로드합니다.

1. `Code` 버튼 클릭
2. `Download ZIP` 선택
3. 다운로드한 ZIP 파일 압축 해제

### 2. Unity Hub에서 프로젝트 열기

1. Unity Hub 실행
2. `Projects → Add → Add project from disk` 선택
3. 압축 해제한 프로젝트 폴더 선택
4. Unity 6.3 LTS로 프로젝트 실행

프로젝트 폴더에는 다음 디렉터리가 포함되어 있어야 합니다.

```text
GamePrototype/
├── Assets/
├── Packages/
└── ProjectSettings/
```

### 3. 프로토타입 실행

Unity 에디터에서 다음 씬을 엽니다.

`Assets/Scenes/Prototype.unity`

이후 상단의 Play 버튼을 누르면 게임을 실행할 수 있습니다.

최초 실행 시 Unity에서 필요한 에셋을 임포트하므로 시간이 소요될 수 있습니다.
